# Evidence

The NetworkWalks assignment requires a screenshot and saved command output for each task.

Add your own evidence files here or inside each task folder, for example:

```text
Task 01 → screenshot.png + whois-output.txt
Task 02 → screenshot.png + whatweb-output.txt
Task 03 → screenshot.png + nslookup-output.txt
Task 04 → screenshot.png + curl-output.txt
Task 05 → screenshot.png + wafw00f-output.txt
Task 06 → screenshot.png + dnsrecon-output.txt
```

The reference findings already documented in this repository come from the supplied assignment PDF. They should not be presented as personal execution evidence.
