# Assignment Reference

## NetworkWalks W2-PM1

**Title:** Footprinting & Reconnaissance Attacks with Multiple Kali Tools

### Tasks from the PDF

1. Run `whois` to find domain registration details.
2. Run `whatweb` to fingerprint web technologies.
3. Run `nslookup` to resolve the domain to its IP address.
4. Run `curl -I` to read HTTP response headers.
5. Run `wafw00f` to detect a Web Application Firewall.
6. Run `dnsrecon` to enumerate DNS records.

### Target

`networkwalks.com`

### Required Evidence

The PDF instructs the learner to save a screenshot and save the command output in a text file for each task.

### Important

The values documented in the task `findings.txt` files are limited to information explicitly shown or stated in the supplied PDF. They are reference material and should be replaced or supplemented with the learner's own captured outputs from Kali Linux.
